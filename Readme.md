**📱 Secure Calculator - Short Summary**

**What it is:** A fully functional, security-themed calculator web app with basic operations (+, -, ×, ÷).

**Files:**
- `index.html` - Structure & layout
- `style.css` - Styling & responsive design
- `script.js` - All calculator logic
- `README.md` - This documentation

**Key Features:**
✅ All basic math operations  
✅ Clean, modern UI with security theme  
✅ Keyboard + mouse support  
✅ Error handling (prevents divide by zero)  
✅ Responsive (works on mobile/desktop)  
✅ Visual feedback & animations  

**How to run:** Just open `index.html` in any browser.

**Tech used:** HTML5, CSS3 (Grid, Flexbox), JavaScript (ES6 Classes, Event Handling).

**Learning points:** DOM manipulation, event handling, state management, responsive design, and clean code organization.

**Purpose:** Educational project demonstrating front-end development with a network security theme.
